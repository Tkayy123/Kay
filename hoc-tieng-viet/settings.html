1Giọng đọcVoice

Cách cài giọng tiếng Việt · How to install a Vietnamese voice
  • Windows 10/11: Settings → Time & language → Language & region → Add a language → Tiếng Việt, tích “Text-to-speech”, cài xong khởi động lại trình duyệt. Dùng Microsoft Edge thì có thêm giọng “HoaiMy / NamMinh (Natural)” tự nhiên hơn.
  • macOS: System Settings → Accessibility → Spoken Content → System voice → Manage Voices → Vietnamese → tải “Linh”.
  • iPhone / iPad: Settings → Accessibility → Spoken Content → Voices → Vietnamese → tải giọng.
  • Android: Settings → System → Languages → Text-to-speech output → Google → cài dữ liệu giọng Tiếng Việt.
